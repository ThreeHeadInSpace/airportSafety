# Окно вылета

Некоммерческий сервис: реальные ограничения пяти аэропортов, история и сравнение времени перелёта. Согласованный HTML сохранён в корне; приложение использует его стили и структуру трёх страниц.

Сайт: https://airport-safety.vercel.app

## Локальный запуск

Node.js 22 или новее: `npm ci`, затем `npm run dev`. Без переменных окружения читается настоящий архив `data/snapshot.json`; его дата показана на экране. Состояния старше 30 минут отображаются серыми.

`npm test` проверяет алгоритмы. `npm run build` собирает production. `npm run collect -- --full` загружает минимум 98 дней публичного архива Telegram. `node scripts/reparse.mjs` пересчитывает локальную историю после изменения парсера.

## Данные и ограничения

Единственный источник: https://t.me/s/favt_info. Чужие базы не копируются. Страницы архива обходятся по `before`, цитаты исключаются. Дубликаты заменяются по ID сообщения. Последние два дня перечитываются для исправлений; еженедельно перечитывается весь период. Удалённые Telegram публикации и правки до доступного периода не гарантируются к восстановлению.

Время хранится в UTC. Явное время `с HH:MM МСК` хранится отдельно от публикации; если оно позже публикации, применяется предыдущий московский день. Другие неоднозначные указания времени отправляются на проверку. Без явного времени используется публикация с отметкой `publication_estimate`. Причины ограничений не приписываются беспилотникам.

Первоначальное состояние неизвестно до первого однозначного сообщения. Неоднозначная публикация переводит затронутые направления в неизвестное состояние до следующего понятного сообщения. Незавершённое ограничение не закрывается: SQL `ended_at` остаётся NULL, `observed_until` хранит последний момент наблюдения. При перерыве сборщика более 45 минут пробел отмечается неизвестным.

Тепловая карта показывает долю известных минут; неполные часы заштрихованы. Статистика исключает неизвестные минуты. Одновременные ограничения направлений считаются один раз. Смена полного режима на частичный не создаёт новый эпизод в итоговой статистике.

Подбор сравнивает одинаковый день недели за последние 90 дней. Минуты вылета совмещаются с минутами прилёта после реальной длительности перелёта; UTC учитывает разные местные даты. Учитывается доля времени с ограничением хотя бы в одном аэропорту среди совместно известных минут. Менее трёх дней — без рекомендации, менее десяти — малая выборка. Это история, не прогноз.

## Supabase и обновления

Используется разрешённый пользователем проект `hvonrzvchwxpdttazphf`; до внедрения таблиц в public не было. Модель: `airport_directory`, `airport_messages`, `airport_events`, `airport_intervals`, `airport_collection_runs`, `airport_snapshots`. Все таблицы с RLS. Публично доступно только чтение снимка публичных сообщений. Привилегированные ключи Supabase не используются.

Схема для нового окружения: `docs/schema.sql`. Функция загрузки проверяет случайный 256-битный ключ приложения по SHA-256 в закрытой схеме, выполняет изменения атомарно и защищается блокировкой и проверкой возраста снимка. После создания схемы администратор должен заполнить `airport_private.ingest_credentials` хешем случайного токена. Сам токен хранится только в GitHub Actions secrets.

Vercel: защищённые переменные `SUPABASE_URL`, `SUPABASE_ANON_KEY`. GitHub Actions: те же и `SUPABASE_INGEST_TOKEN`. Не добавлять ключи в Git. Проект Vercel связан с main; публикация при push автоматическая.

Сбор: минуты 07, 22, 37, 52 каждого часа UTC; полная сверка воскресенье 03:22 UTC. Возможны задержки GitHub Actions. Успехи и ошибки записываются в базу, последняя успешная проверка видна на сайте. Одновременные запуски стоят в очереди. Ручной запуск доступен в Actions → Collect Rosaviatsia messages.

## Эксплуатация

Проверяйте неуспешные Actions и `airport_collection_runs`, а также `airport_messages where review=true`. Исправления парсера требуют полного импорта. Рекомендуется периодический экспорт базы: бесплатный тариф не заменяет резервное копирование. Нет гарантии доступности публичной веб-версии Telegram, задержек публикаций или полноты удалённой истории.

Проверка безопасности Supabase: отсутствие политик на закрытых таблицах намеренно запрещает доступ. Предупреждение о доступной anon функции SECURITY DEFINER ожидаемо: перед каждой записью проверяется отдельный случайный токен, неверный токен проверен и отклонён. Подробнее: https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable
